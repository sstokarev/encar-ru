# Публикация расширения в магазинах

Цель: клиент ставит расширение **в один клик по ссылке**, без «скачайте архив» и «включите режим разработчика». Всё, что можно было подготовить заранее, уже лежит в репозитории — ниже только то, что требует вашего аккаунта.

Загружаемый файл: `site/encar-ru-extension.zip` (собирается командой `npm run build:extension`, попадает в сборку автоматически). Скачать текущий: <https://sstokarev.github.io/encar-ru/encar-ru-extension.zip>

---

## 1. Chrome Web Store — основной путь

Покрывает Chrome, а также Яндекс.Браузер и Opera (они ставят расширения из этого же магазина). Edge — либо один тумблер у пользователя, либо отдельная публикация (см. п. 2).

**Что нужно от вас:** аккаунт Google + разовый взнос **$5** (единожды за аккаунт, не за расширение) и заполнение формы. Проверка обычно занимает от нескольких часов до нескольких дней.

### Шаги

1. Открыть <https://chrome.google.com/webstore/devconsole>, войти в аккаунт Google, оплатить регистрацию разработчика ($5).
2. В консоли: **«Добавить новый элемент»** → загрузить `encar-ru-extension.zip`.
3. Заполнить карточку — тексты ниже готовы к вставке.
4. **Видимость: «По ссылке» (Unlisted).** Рекомендую именно её: расширение не появится в поиске магазина и его не найдут конкуренты, но клиент по вашей ссылке ставит его в один клик. Переключить на публичную можно в любой момент.
5. Отправить на проверку. После одобрения магазин даст постоянную ссылку вида `https://chromewebstore.google.com/detail/<id>` — пришлите её мне, я поставлю её на страницу-инструкцию вместо нынешнего архива.

### Тексты карточки

**Название** (до 75 знаков)

```
Encar по-русски — цена под ключ в РФ
```

**Краткое описание** (до 132 знаков)

```
Показывает рядом с ценой на encar.com цену автомобиля под ключ в рублях и полный расчёт: пошлина, сборы, доставка.
```

**Подробное описание**

```
Расширение для тех, кто подбирает автомобиль на корейском encar.com.

Рядом с каждой ценой в вонах появляется цена в рублях — та, во сколько машина обойдётся под ключ в России. На странице автомобиля цена раскрывается в полный расчёт: цена лота, таможенная пошлина, утилизационный сбор, сбор за оформление, доставка и комиссия. Там же — кнопка, чтобы отправить выбранный автомобиль менеджеру.

Как это работает:
• расчёт идёт прямо в браузере, на основе данных открытой страницы;
• курс валют — официальный курс Центробанка РФ, дата курса видна в расчёте;
• ставки пошлин и сборов соответствуют действующим правилам для физических лиц;
• если каких-то данных в объявлении нет (например, мощности двигателя), строка честно показывается прочерком, а итог — как «от», а не выдуманным числом.

Расширение также переводит на русский основные подписи интерфейса encar: год, пробег, тип топлива, разделы меню.

Никаких аккаунтов и настроек: поставили — и цены появляются сами на всех страницах encar.com.

Конфиденциальность: расширение не собирает и не передаёт никаких персональных данных, не использует аналитику и работает только на страницах encar.com. Исходный код открыт: github.com/sstokarev/encar-ru
```

**Категория:** «Покупки» (Shopping)
**Язык:** русский

**Ссылка на политику конфиденциальности**

```
https://sstokarev.github.io/encar-ru/privacy.html
```

**Сайт поддержки**

```

```

### Что ответить на вопросы формы

**Единственное назначение (single purpose)**

```
Расчёт и отображение итоговой стоимости автомобиля в рублях на страницах encar.com.
```

**Зачем нужен доступ к сайту (host permission `*://*.encar.com/*`)**

```
Расширение читает цену и характеристики автомобиля на открытой странице encar.com и отображает рядом рассчитанную цену в рублях. Без доступа к этим страницам функция невозможна. Доступ к другим сайтам не запрашивается.
```

**Удалённый код (remote code)**

```
Нет. Весь исполняемый код входит в пакет расширения. Загружаются только данные: файл настроек с тарифами и курс валют ЦБ РФ.
```

**Сбор данных**: отметить, что **никакие** категории данных не собираются, и подтвердить три декларации (не продаём третьим лицам, не используем не по назначению, не используем для оценки кредитоспособности).

### Скриншоты

Нужен минимум один, размер **1280×800** или 640×400, PNG или JPEG. Подойдут два вида: список автомобилей с рублёвыми ценами и страница автомобиля с раскрытым расчётом. Если нужно — соберу их и положу в репозиторий, скажите.

## 2. Microsoft Edge Add-ons — бесплатно, стоит сделать заодно

Тот же самый zip, регистрация **без оплаты**: <https://partner.microsoft.com/dashboard/microsoftedge>. Тексты выше подходят полностью. Даёт установку в один клик пользователям Edge, который в России встречается часто.

Без этой публикации пользователь Edge тоже может поставить расширение из Chrome Web Store, но ему придётся один раз согласиться на «Разрешить расширения из других магазинов» — лишний шаг, которого лучше избежать.

## 3. iPhone и Android — честная картина

- **iPhone (Safari).** Расширений вне App Store не существует. Чтобы получить установку в один клик, нужна учётная запись Apple Developer (**$99 в год**) и приложение-обёртка с расширением Safari, проходящее ревью Apple. Пока этого нет, на iPhone работает закладка: код вставляется в адрес закладки один раз, дальше — нажатие на неё на странице encar.
- **Android (Chrome).** Расширения не поддерживаются в принципе — только закладка. Исключение: Яндекс.Браузер для Android умеет ставить расширения из Chrome Web Store, там сработает п. 1.

---

## 4. После публикации

- Пришлите ссылку из магазина — заменю ей блок с архивом на странице-инструкции.
- Обновления после этого доезжают до клиентов **сами**: новую версию достаточно загрузить в консоль магазина, переустанавливать ничего не нужно.
- Версия в `manifest.json` должна расти с каждой загрузкой — она берётся из `VERSION` в `src/main.ts`, сборка падает, если они разошлись.
